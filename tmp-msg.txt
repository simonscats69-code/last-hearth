fix(rate-limit): 429 на каждом ударе по боссу; fix(map): прыгание и переполнение

429 «Слишком много попыток авторизации»
- authLimiter (30/мин по IP) висел через router.use() ДО авторизации и
  ограничивал ВСЮ игру: десяток запросов в минуту (профиль, инвентарь,
  статус, локации, инсайты) исчерпывал лимит, и удар по боссу отваливался.
- Лимиты перестроены по слоям: антифлуд по IP 120/мин до авторизации
  (только против ботов без initData); атаки 30/мин; покупки 20/мин;
  общий лимит игрока 120/мин ПОСЛЕ validatePlayer и по id игрока.
- Убран ключ по IP для игроков: в мобильном CGNAT один адрес делят
  десятки игроков, и они блокировали друг друга.
- Клиент больше не повторяет запрос при 429. Раньше 429 был исключением из
  правила «4xx не повторяем»: сервер говорил «слишком быстро», клиент слал
  тот же запрос ещё два раза с нарастающей паузой — одна ошибка лимита
  разгонялась в три запроса.

Карта
- mousemove вызывал selectMapLocation() на каждое событие, а та переключала
  display блока деталей и кнопки «Перейти»: блок мигал, всё ниже сдвигалось,
  карта «ездила» под курсором. Теперь DOM обновляется только при смене
  выбранной локации.
- Перерисовка canvas идёт через requestAnimationFrame и не чаще одного раза
  на кадр; подсветка обновляется только при смене локации под курсором.
- Переполнение: у .map-container убрана фиксированная высота
  calc(100% - 60px), canvas получил display:block, max-width 340px и
  max-height 46vh (сжимается по вертикали, пропорции сохраняются),
  touch-action: manipulation (больше не оттягивается пальцем).
- Пилюли подготовки и подсказка риска стали компактнее и выровнены по
  ширине карты; у .map-info зафиксирована min-height, поэтому блок больше
  не меняет высоту.
- Убран дубль правила .map-location-info в CSS: второе перебивало размеры.

Примечание: ошибки Lottie в консоли — внутренний плеер Telegram
(web.telegram.org, tlottie), в коде игры Lottie нет.
