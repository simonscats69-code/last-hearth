# Промпты для боссов — Last Hearth (постапокалипсис)

## Общие требования ко всем 10 картинкам
- Формат: PNG, 1024x1024 (потом ужмутся до 256)
- Стиль: единый game icon, post-apocalyptic, painterly, gritty texture, rust and grime
- Фон: тёмный, однотонный (#1a1512), лёгкая виньетка, БЕЗ мелкого мусора по краям
- Композиция: портрет по грудь / морда крупно, занимает 80% кадра, поля ~10%
- Свет: один источник сверху-слева, токсичное зелёное или кроваво-красное свечение акцента
- НЕ делать: фотореализм, мультяшность, текст/буквы на картинке, оружие во всю длину
